# 🚀 Guía de Instalación y Ejecución - Brillé Joyería 🌸

Sigue estos sencillos pasos para clonar, compilar y ejecutar el proyecto localmente.

## 📋 Requisitos Previos
* **.NET 8.0 SDK** o superior instalado.
* **Git** para la gestión de versiones.

## 💻 Pasos para Ejecutar en Windows / Linux / macOS

1. Abrir la terminal o Símbolo del Sistema.
2. Navegar hasta la carpeta del proyecto C#:
   ```bash
   cd EcommerceApp
1. Restaurar paquetes y compilar la solución, en terminal:

dotnet build
2. Ejecutar la aplicación web:

dotnet run
3. Abrir el navegador e ingresar a la URL local indicada:

http://localhost:5276

⚙️ Acceso al Panel de Administración
Ruta: /Admin/Login
